## A. Mathematical argument and availability qualification

Within each canonical task t, let Z_ti=(Y,E,C) be iid over n_t independent eligible source groups, exactly one predeclared canonical target per group. Condition on fitted models/thresholds and a label/eligibility rule fixed before seeing evaluation predictions. No outcome-driven sampling, group replacement, cross-task duplication or ignored related sources. Counts may be conditioned on, but eligibility must define the same population. True precision/recall contrasts require positive population denominators. This theorem does not establish the real groups' independence, silver-label semantic correctness, representativeness or training-selection uncertainty.

Write j=4Y+2E+C and K_tj=sum_i 1[Z_ti=j]. Then K_tj is marginally Binomial(n_t,p_tj), although eight counts within a task are dependent. Each exact Clopper–Pearson interval has two tails a=1/1920, so P(p_tj outside I_tj)≤2a. The union bound across 24 cells gives P(p in R)≥1−48a=0.975, where R=(product I_tj) intersected with the three simplexes. Intersecting with those simplexes cannot exclude a true probability vector already in all marginal intervals. No independence between the 24 confidence events is required. Numerical CP endpoints must be outward-certified, never merely approximate beta quantiles.

Define weighted totals T_m=sum_tj π_t Y m p_tj, D_m=sum_tj π_t m p_tj, D_Y=sum_tj π_t Y p_tj and N_R=sum_tj π_t Y(C−E)p_tj. The exact estimands are ΔP=T_C/D_C−T_E/D_E and ΔR=N_R/D_Y. They are ratios of task-standardized totals, not averages of per-task ratios. On {p in R}, valid global outer projections contain each defined true contrast. The exact symmetry intersection is a pointwise set identity when its rational invariance guard holds, so data-dependent application of that proved identity does not weaken coverage. Rational weak-duality residual correction and feasible witnesses protect outward bounds; 0.002 is an extremum approximation tolerance, not permission to move a decision endpoint inward.

**Availability matters.** For endpoint k, let A_k be the event that the method reports an estimable, certified interval. The guarantee is P(A_k AND true Δ_k outside I_k)≤0.025, and the probability of any such certified error across both endpoints is ≤0.025 on the same region event. If both intervals are always available, simultaneous coverage is at least 0.975. Otherwise P(true Δ_k in I_k | A_k) need not be ≥0.975. Never claim conditional-on-availability coverage from the union-bound proof. For theoretical accounting only, assigning the whole parameter range to unavailable outputs yields an unconditional set-valued coverage statement; operational output remains NA/non-success, never a fabricated [-1,1] interval counted as a useful success.

Under the union null (ΔP≤0 OR ΔR≤−0.02), false joint success implies the true vector missed R or a numerical proof defect. With valid certificates and no success for NA/failure, false joint claim probability is at most 0.025. No extra endpoint Bonferroni is needed for the conjunctive claim; the 24-cell region is already simultaneous. Conditional interval coverage, availability and practical power remain different quantities.

The CP argument applies to the independent canonical-target population only. Duplicate nominal IDs cannot turn correlated children into independent trials. Multiple eligible targets per parent require a separately justified clustered moment region; ordinary aggregated multinomial counts are not valid there. The audit's Option B derivation is not implemented or adopted.

### Why 2,000 per scenario

The coverage bound comes from the theorem. Monte Carlo is for implementation/error-inflation diagnostics and availability/width behavior. At an event probability 0.025, n=2,000 has standard error sqrt(.025×.975/2000)=0.003491 (ordinary normal-approximate 95% half-width 0.00684). Exact CP Monte Carlo limits are reported; simultaneous intervals are wider. This resolution can expose substantial inflation, not prove equivalence to 0.025 or detect arbitrarily small excess. Deterministic binomial-tail calculations will report sensitivity at diagnostic event probabilities .03, .04 and .05; these are error-diagnostic sensitivity, not EviConsist statistical power.

No rule requires every finite-simulation upper limit to be below 0.025. For the fixed family of at most 90 applicable error diagnostics (≤6 per independent-source scenario), flag excess using one-sided exact Binomial(2000,0.025) tests at 0.01/90. These diagnostics include region noncoverage, precision and recall certified noncoverage, joint false claim, and applicable marginal false claims. All error tests use **all 2,000 attempted eligible-model datasets** as denominator; certified noncoverage counts unavailable outputs as no *issued incorrect interval*, while unavailability is separately and prominently reported. Conditional certified-only coverage is descriptive, never tested as if its null were guaranteed by the theorem. A significant excess is an implementation/model diagnostic stop, not the sole definition of mathematical validity. No optional sample-size extension or post-result threshold changes.

## Pass/fail/inconclusive and revision rules

- **A supported:** proof is coherent under the explicit independent-unit model, with the availability qualification; real-population assumptions remain separate.
- **B supported for the tested design only:** a complete 30,000-dataset study and all audit checks finish under approved resources, with no hard defects or excess-error stop and all numerical/NA behavior accounted for. This is evidence of implementation fidelity, not a universal theorem proof or practical-power approval.
- **C supported:** sufficient fresh independent, eligible, rights-cleared source counts are established and justified width/availability plus later paired power support the unchanged claim. No deterministic example alone supplies this.
- Hard proof/certificate/inside-region contradiction, grouping misuse or reproducible estimable optimizer failure => requires mathematical or implementation revision; do not expand n or loosen limits to hide it.
- Incomplete simulations, unapproved resources, unresolved real-source frame, or inadequate information about practical sizes => inconclusive/infeasible for advancing, never a statistical pass.

The present decision must select one requested outcome: (1) ready for a prospectively frozen validation run only if its prerequisites are met; (2) mathematical/implementation revision if a real proof/certification gap is found; or (3) mathematically defensible but presently uninformative/infeasible if the supported frame/resources cannot supply an informative study.
